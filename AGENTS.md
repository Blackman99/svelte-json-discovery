# Repository Agent Guidance

Follow the repository's existing package, testing, linting, Changesets, and CI
conventions. Preserve the read-only `JsonViewer` compatibility surface unless a
spec explicitly authorizes a breaking change.

## Agent skills

- Use `docs/agents/issue-tracker.md` to publish specs and implementation tickets.
- Use `docs/agents/triage-labels.md` for issue readiness and triage state.
- Use `docs/agents/domain.md` to find the domain vocabulary and decision records.
