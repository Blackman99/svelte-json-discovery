Initial release: standalone Svelte 5 port of the `struct` (JSON) view from discoveryjs/discovery — type-aware collapsed previews, expand/collapse with auto-expand depth, pagination for large collections, string truncation with "as text" mode, match highlighting, value actions popup (copy path / copy JSON), Set/Date/RegExp/Error/bigint/TypedArray support, and light/dark/auto theming.
