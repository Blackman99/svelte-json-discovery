# Issue Tracker

The project uses GitHub Issues in `Blackman99/svelte-json-discovery`:

https://github.com/Blackman99/svelte-json-discovery/issues

Publish specs as parent issues and implementation work as one issue per
tracer-bullet ticket. Create tickets in dependency order so their `Blocked by`
sections can reference real issue numbers. Apply `ready-for-agent` only when an
issue is self-contained and can be started without another product decision.

Use the GitHub CLI from the repository checkout for issue and label operations.
Do not close or rewrite parent spec issues when publishing child tickets.
