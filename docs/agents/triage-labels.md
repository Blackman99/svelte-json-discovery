# Triage Labels

Use exactly one readiness/triage state when it applies:

| Workflow state | GitHub label |
| --- | --- |
| Unreviewed work | `needs-triage` |
| Missing required information | `needs-info` |
| Self-contained for an implementation agent | `ready-for-agent` |
| Requires a human-only decision or action | `ready-for-human` |
| Intentionally declined | `wontfix` |

Feature specs and approved implementation tickets also use the existing
`enhancement` label. Documentation-only work may additionally use the existing
`documentation` label.
